# 安全说明

默认只绑定 `127.0.0.1`，不要直接改成 `0.0.0.0` 暴露到公网。

- `configure` 会生成随机 `ALPHAFORGE_API_TOKEN`；
- 不要提交 `.env`；
- 不要在截图、日志或报告中展示完整 Token；
- Tiingo Token 仅用于本机数据同步；
- 真实行情位于 `workspace/data`，不提交 Git、不公开分发；
- `strategies/` 中的 Python 代码会在容器内执行，应只运行可信代码；
- 容器对 `workspace/` 具有写权限；
- API 只运行注册策略，不接受任意 Python 源码上传；
- 当前服务是本地研究后端，不是公网多租户平台；
- 正式对外服务需要额外的 TLS、反向代理、身份认证、审计、限流和容器级资源隔离。
