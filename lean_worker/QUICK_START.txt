AlphaForge Local LEAN Runtime v1.1.3

Prerequisites:
  1. Install and start Docker Desktop.
  2. Obtain your own Tiingo API token.
  3. Real market data is not included in this ZIP.

Windows PowerShell:
  powershell.exe -ExecutionPolicy Bypass -File .\scripts\configure.ps1
  powershell.exe -ExecutionPolicy Bypass -File .\scripts\start.ps1
  powershell.exe -ExecutionPolicy Bypass -File .\scripts\data-sync.ps1 -Full
  powershell.exe -ExecutionPolicy Bypass -File .\scripts\test.ps1

macOS Terminal:
  chmod +x scripts/*.sh
  ./scripts/configure.sh
  ./scripts/start.sh
  ./scripts/data-sync.sh --full
  ./scripts/test.sh

Stop:
  Windows: .\scripts\stop.ps1
  macOS:   ./scripts/stop.sh

Shutdown Compose but preserve data:
  Windows: .\scripts\shutdown.ps1
  macOS:   ./scripts/shutdown.sh

API docs: http://127.0.0.1:18081/docs
Full guide: docs/FULL_USER_GUIDE_zh.md
