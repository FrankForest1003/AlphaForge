## 最低要求核对

| 课程要求 | 当前集合 | 结论 |
|---|---:|---|
| 至少8篇研究论文 | 10篇 | 满足 |
| 至少5篇发表于最近五年 | 7篇集中于2023–2025；若计入2021则为8篇 | 满足 |
| 至少2篇来自信誉良好的出版机构 | 10篇均有正式期刊或会议来源 | 满足 |
| 至少1篇综述论文 | 2篇正式综述 | 满足 |

与旧版论文集合不同，当前10篇均对应最终 Literature Review Report 的正式参考文献，不再依赖 AgentCoder、MapCoder 或 TradingAgents 等预印本来满足最低论文数量。

## 六条研究主线

当前集合覆盖：

1. 金融机器学习与模型比较；
2. 风险感知投资组合与金融回测；
3. 金融 Multi-Agent 系统；
4. Explainable 与 Self-reflective Financial LLM；
5. Backtest Overfitting 与选择偏差；
6. Serious Games 与金融教育。

这些研究共同支持 AlphaForge 的核心设计：公平的 Human-AI 信息隔离、参数型 Agent、固定实验合同、真实 LEAN 回测、确定性风险评分、可审计策略谱系和跨轮学习反馈。

## 使用与许可提示

这些 PDF 是团队的研究输入，不是应用运行资产。公开仓库、网站或最终交付物是否可以直接分发论文全文，取决于各论文和下载来源的许可。若无法确认再分发权限，应仅保留规范的文献元数据、DOI 和授权链接，并从公开 Git 历史中移除 PDF。
